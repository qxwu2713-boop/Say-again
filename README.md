# -# 再讲一遍 · Say Again

> 关于那天，让文字再讲一遍。

「再讲一遍」是一个文字版的“那年今日”轻量记录应用 Demo。

我们总会在某个瞬间写下一句很动人的话：日记片段、书里的划线、下班路上的感慨，或是听歌时冒出来的心情。但很多句子写完就被遗忘了。这个应用会在每次打开时，让过去标记过的一句话随机出现，带你回到那天。

## 功能

- **今日回响**：随机展示一条过去标记过的金句，可继续随机切换或进入原笔记详情。
- **写下此刻**：记录文字、添加本地配图，并把值得未来再见的句子标记为金句。
- **我的笔记**：按时间倒序浏览所有记录，查看完整原文、图片与金句。
- **本地保存**：使用浏览器 localStorage 持久化笔记；刷新页面不会丢失。
- **Demo 交互**：截图和语音入口会提示正式版能力，当前版本以文字记录为主。

## 视觉

- 390 × 844 手机竖屏比例
- 米白纸张底色、低饱和暖橘与豆沙粉强调色
- 手绘感爱心、纸张、小人底部导航
- 用户内容优先使用「江西拙楷」字体，并配备楷体回退

## 本地运行

无需安装任何依赖。

直接双击 `index.html`，或用浏览器打开该文件即可。

## 部署到 Vercel

1. 创建一个 GitHub 仓库。
2. 将 `index.html` 上传到仓库根目录。
3. 在 Vercel 中选择 **Add New → Project**，导入该 GitHub 仓库。
4. Framework Preset 选择 **Other**，构建命令与输出目录留空。
5. 点击 Deploy。

之后每次向 GitHub 的 `main` 分支提交更新，Vercel 会自动发布新版本。

## 数据说明

- 笔记保存在当前浏览器的 localStorage 键 `zjyb_notes` 中。
- 图片以 FileReader 生成的 data URL 形式保存。
- 数据不会自动同步至其他设备或浏览器。
- 如需恢复初始示例数据，可在浏览器开发者工具中删除该 localStorage 键。
